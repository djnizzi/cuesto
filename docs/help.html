01

getting started

1

launch CUEsto

Open CUEsto from your applications folder, or double-click an existing .cue file and choose to open it with CUEsto. The editor opens with 9 default tracks pre-spaced at 3-minute intervals so you can start building immediately.

2

open an existing CUE sheet

Click the Open File icon in the Top Bar to select an existing .cue file. The editor will populate with the tracks and metadata from your file.

3

start editing

Click directly on any track field to edit the title, performer, start time, or duration. Changes cascade automatically — editing a start time recalculates the previous track's duration.

02

linking an audio file

Linking an audio file to your CUE sheet unlocks precise duration data and automatic metadata extraction.

1

click the disc icon

Click the Disc Icon next to the "file name" field in the header.

2

select your audio file

Choose your audio file — MP3, WAV, FLAC, and more are all supported.

3

CUEsto does the rest

  • Extracts and populates Title, Performer, Date, and Genre from the file's metadata tags.
  • Multi-Artist Support: multiple artists are automatically detected and joined with ; in the editor.
  • Displays the precise Total Duration of the audio file.
  • Automatically calculates the duration of the Final Track.
  • Suggests the audio filename as the default when saving.
03

importing from 1001tracklists

CUEsto integrates directly with 1001tracklists.com through its built-in browser.

1

open the browser

Click the 1001tracklists logo in the Top Bar imports section to open the internal browser.

2

navigate to the tracklist

Search for and navigate to the tracklist page you want to import.

3

click import

Click the import icon in the browser's top bar. The grid will automatically populate with metadata and tracks from the page.

Note: sometimes 1001tracklists may not provide exact timings. In these cases, CUEsto will import the track titles and performers but leave the timing fields empty for you to fill in manually.
04

importing from GnuDB

Retrieve high-quality metadata from the GnuDB database using a CD ID.

1

open the GnuDB modal

Click the GnuDB logo in the Top Bar. A modal will appear showing the current performer and album title being searched.

2

choose what to import

Use the checkboxes to select exactly which fields to update: Header (Artist, Album, Year, Genre), Track Titles, Track Performers, or Start Times/Durations. If a field is currently empty, GnuDB will always populate it regardless of your selection.

3

enter the CD ID and fetch

Enter the GnuDB CD ID (e.g., 860a8c86) and click the get metadata icon. CUEsto fetches and fills the data, and saves the CD ID as a REM GNUCDID line in your CUE file.

05

importing from Discogs

CUEsto provides a powerful integration with Discogs, the premier music database. You must connect your account before using this feature.

1

open the Discogs modal

Click the Discogs logo. A modal appears showing the performer and album title CUEsto is searching for.

2

enter the release code

Enter the numeric release ID (e.g., 153184). CUEsto also accepts formats like r153184. For multi-disc releases, specify the disc number.

3

choose what to import

  • Header: Artist, Album Title, Year, Genre.
  • Track Titles / Performers: updates all imported tracks.
  • Start Times/Durations: uses raw Discogs durations.
  • Interpolate Start Times: (requires a linked audio file) adjusts Discogs durations using total length for high-precision start times.

The release ID is saved as a REM DISCOGS line in your CUE file.

06

importing from MusicBrainz

Import extremely detailed metadata — including barcode and label info — from MusicBrainz.

1

open the MusicBrainz modal

Click the MusicBrainz logo. The modal shows what you are searching for and provides a "search on musicbrainz.org" link.

2

enter the Disc ID

Enter the MusicBrainz Disc ID (e.g., qT8E_p...) and choose your selective overwrite options (Header, Titles, Performers, Timings).

3

enhanced metadata

CUEsto automatically captures BARCODE, LABEL, and CATALOG number, storing them as REM lines. The Disc ID is saved as REM MUSICBRAINZ_DISCID.

07

internal browser & context menu

CUEsto features a customized internal browser that makes finding metadata IDs effortless.

🖱️

smart right-click actions

  • "use this disc id" — sends the CD TOC/Disc ID to the MusicBrainz modal.
  • "use this release code" — sends the release ID to the Discogs modal.
  • "use this gnucdid" — sends the CDID to the GnuDB modal.
⬅️

navigation controls

The browser header includes Back and Forward buttons so you can browse freely without losing your place.

📋

standard actions

Localized right-click options for copy, copy link, and open in new window are always available.

08

importing from Audacity

CUEsto supports importing timing and label data from Audacity Labels files.

1

export labels from Audacity

In Audacity, go to Tracks → Add New → Label Track, then export via File → Export → Export Labels… as a .txt file.

2

import in CUEsto

Click the Audacity logo in the Top Bar and select the exported .txt file.

3

conditional update

  • Start Times: all track timings are unconditionally updated from the Audacity file.
  • Titles/Performers: only updated if the current fields are empty — so you can re-sync timings without losing manual corrections.
09

splitting audio

CUEsto includes a built-in audio splitting engine powered by FFmpeg. Slice a single large audio file into individual tracks based on your CUE sheet.

1

link the audio file

Follow the steps in the Linking an Audio File section to connect your source file.

2

review timings

Ensure your track start times and durations are correct in the grid before splitting.

3

click split

Click the Scissors icon in the Top Bar. A dedicated modal will appear showing the progress of each track being created.

4

find your files

Tracks are saved in the same directory as the source file using the naming convention: Track## - Title.ext. Click the Open Folder icon to jump directly to your new files in Explorer.

10

editing tracks

✏️

title & performer

Click directly on any text field to edit the track title or performer inline.

⏱️

start time

Edit the start time of a track. The duration of the previous track will be automatically recalculated to maintain continuity.

⏳

duration

Changing a track's duration shifts the start times of all subsequent tracks automatically — no manual adjustments needed.

🎵

final track duration

  • Calculated automatically when an audio file is linked.
  • Uses REM TOTAL DURATION if present in the CUE file.
  • Hidden if neither source is available, to prevent confusion.
➕

add / remove / clear

  • Add Row: click the add row icon at the bottom of the tracklist — new tracks default to 3 minutes.
  • Trash Icon: remove any track instantly.
  • Clear Editor: click the clear icon in the Top Bar to reset the entire sheet (a confirmation modal prevents accidents).
11

text editing tools

Click the Edit icon in the Top Bar to open the Text Editing Modal. These batch tools normalize your track metadata in one click.

🔄

change separator

Scan all track performers and change a specific separator across the entire tracklist — e.g., from , to ;.

✂️

split title to title & performer

If your track titles contain the performer name (e.g., Song Name - Artist), specify the separator and CUEsto will automatically split them into the correct fields.

↔️

swap titles & performers

Quickly flip the contents of the Title and Performer fields for all tracks at once.

🔡

change to propercase

Automatically convert all track titles and performers to Propercase — e.g., SONG NAME becomes Song Name.

12

viewing the raw CUE sheet

Inspect or verify the raw CUE sheet text at any time before saving.

1

open the viewer

Click the "view cue" icon at the bottom of the editor. A new read-only window will open displaying the formatted CUE content.

2

syntax highlighting

Each CUE command is color-coded for easy reading:

Green — REM
Red — TRACK
Magenta — INDEX
Cyan — PERFORMER
Yellow — TITLE
Blue — FILE
13

settings & personalization

Click the Language/Settings (Globe) icon on the right side of the Top Bar to open the Settings Modal.

🌍

language selection

Choose your preferred language: English, Deutsch, Español, Français, or Italiano. All interface elements and tooltips update immediately.

🌙

theme toggle

Switch between Light Mode (Sun icon) and Dark Mode (Moon icon). Your preference is saved automatically and persists when you restart the application.

14

connecting to Discogs

To use the Discogs import feature, connect your Discogs account using OAuth authentication. The import button in the Top Bar will be dimmed until you do.

1

open settings

Click the Language/Settings (Globe) icon in the right side of the Top Bar.

2

connect your account

Scroll to the Discogs Account section and click Connect to Discogs. Your default browser will open the Discogs authorization page.

3

authorize and return

Log in to your Discogs account and authorize CUEsto. Once authorized, the Discogs section will show your username and the import button becomes active. To disconnect, click Disconnect in the Settings modal.

15

tips

⏱️

Time Format: times are displayed in MM:SS:FF (Frames). CUE sheets use 75 frames per second.

📁

File Reference: ensure the "File" field matches the actual audio file name (e.g., mix.mp3) so apps that read CUE sheets can find the audio.

🔄

Re-sync timings: use the Audacity import to update timings without losing your manually entered track titles and performers.

💿

GnuDB persistence: once you import from GnuDB, the CD ID is saved as a REM GNUCDID line — so you can always re-fetch the same release later.
