features

everything you need

packed with powerful features wrapped in a beautiful, intuitive interface

✂️

audio splitting

slice a large mix or recording into individual tracks using the built-in FFmpeg engine. tracks are saved automatically with a clean naming convention, right next to your source file.

⏱️

smart time editing

edit any start time or duration and CUEsto automatically recalculates the rest. shift an entire tracklist in seconds without touching every row manually.

🎵

audio integration

link your audio file and CUEsto extracts title, artist, year, and genre automatically. multi-artist tags are fully supported, and the final track duration is calculated for you.

🔍

built-in metadata browser

search MusicBrainz, Discogs, GnuDB, and 1001Tracklists from a customized internal browser with back/forward navigation and smart right-click actions that send ids directly to the editor.

✏️

batch text tools

swap titles and performers, change separators, split "title — artist" fields in one click, or convert everything to propercase across your entire tracklist instantly.

📄

CUE viewer with syntax highlighting

inspect your raw CUE sheet at any time in a dedicated read-only window with full syntax highlighting — metadata, tracks, timings, performers, and file references each in their own color.

the story

why CUEsto?

1

the pain we solved

creating CUE files has always been a tedious process. you had to either manually write text files with precise timestamps or use complicated, outdated software. we knew there had to be a better way — a tool that was both easy to use and powerful enough for professional work.

2

what is a CUE file?

a CUE sheet (or CUE file) is a metadata file that describes how the tracks of a cd or audio file are laid out. it contains information like track titles, performers, and most importantly, the precise timestamps where each track begins. CUE files are essential for burning audio cds, organizing large audio recordings, and ensuring seamless playback across multiple tracks.

3

our solution

CUEsto was born from frustration with existing tools. we built an application that combines the simplicity of a modern interface with the power of professional features. whether you're creating a CUE file for the first time or managing hundreds of audio projects, CUEsto adapts to your workflow and helps you get the job done faster.
